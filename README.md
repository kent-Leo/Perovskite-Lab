**比 Origin 更快、更简单的钙钛矿传感科研工具箱**

做钙钛矿荧光传感的你，是否总被 Origin 繁琐操作拖累？
导入数据、调图层、反复拟合、保存工程，耗大量时间。

Perovskite-Lab 面向卤化物钙钛矿量子点、比率荧光探针、重金属检测场景，
点开浏览器就能用，省去复杂学习成本。

## ✨ 核心亮点
- 🚀 更快：Origin 半小时的光谱处理、拟合工作，十几秒完成
- 🪄 更简单：内置传感方向标准算法，不用记忆复杂菜单
- 🧪 课题专属：PL / UV‑Vis 光谱、Stern‑Volmer猝灭、比率探针分析
- ⚗️ 实验计算：前驱体摩尔浓度、试剂称量、梯度稀释
- 📋 多工作表：分组管理多组实验数据，本地持久存储
- 🔒 隐私安全：所有数据保存在浏览器本地，不上传服务器

## 🖥️ 桌面端（macOS / Windows）
现在也能装成本地 App，双击即用，不再依赖浏览器标签页。

```bash
npm run app:dev      # 本地启动桌面端
npm run dist:mac     # 打包 dmg / zip（当前架构）
npm run dist:win     # 打包 Windows 安装包（x64）
npm run test:desktop # 启动打包产物做冒烟测试
```

桌面端沿用同一套前端与 AI 中继，工作区与密钥仍保存在本机。
支持把整个工作区存成 `.plab` 项目文件（`⌘S` / `⌘O`，或双击文件），下次打开继续编辑；旧的工作区备份 JSON 也能直接打开。
详见 [桌面端 Electron 打包（2026.11.4）](docs/桌面端Electron打包-v0.9.4-2026.11.4.md)
