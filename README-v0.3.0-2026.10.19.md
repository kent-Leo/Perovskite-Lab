# Perovskite Lab v0.3.0（2026.10.19）

本版已将 Origin 式工作表接入光谱工作台、对象筛选、校准与检出限、浓度梯度。

## 打开

双击同目录的 `打开前端-v0.3.0-2026.10.19.command`。默认访问 `http://127.0.0.1:4173/`，运行期间保留终端窗口，结束时按 Ctrl+C。ZIP 请先完整解压。

本地启动只需要 Python 3；ZIP 已包含构建文件。修改源码时再安装 Node.js 和 pnpm 依赖。

## 文件

- `src/`：可继续编辑的 React + TypeScript 源码。
- `dist/`：可直接由启动脚本提供的构建网页。
- `docs/四页工作表接入-v0.3.0-2026.10.19.md`：本版使用方法、验证结果和 Git 合并命令。
- `tests/browser/integration-v0.3.0-2026.10.19.spec.ts`：四页接入测试。

本版图表、数据与模板导出文件名均带 `v0.3.0` 和上海时区的 `YYYY.M.D` 日期。

原有独立工作表演示入口继续保留，显示组件版本 v0.2.0；主应用版本为 v0.3.0。
