# Perovskite Lab v0.3.4（2026.10.21）

双击本目录的 `打开前端-v0.3.4-2026.10.21.command`，即可使用已构建的网页。默认地址为 http://127.0.0.1:4173/ 。如旧服务占用端口，先在旧服务终端按 Ctrl+C，再启动本版。

## 浓度梯度

- 母液浓度单位、配制后溶液浓度单位分别选择，支持不同尺度计算。
- 浓度单位统一显示为 mol/L、mmol/L、µmol/L、nmol/L、mg/L、µg/L。
- 切换同类单位时自动换算已有数值，溶液实际浓度和配液用量保持一致；输入新目标浓度后按当前单位重新计算。
- 例如母液 1 mmol/L、目标 1 µmol/L、最终体积 10 mL，需取母液 10 µL。
- 配液表与 Excel 导出同步使用目标单位，导出同时记录母液浓度及其单位。
- 空白行和无效输入保持原位；存在无效浓度或超出定容体积时禁用导出。
- 摩尔浓度与质量浓度之间需要物质的摩尔质量，不能直接切换；本版仍分别支持这两类浓度的内部换算。

## 兼容与保存

旧工作区中的 μM、µM、mM、nM 等写法自动转换为完整单位，数值保持原有尺度。原有浏览器存储键不变，母液与目标单位均自动保存。

恢复原工作区需要使用同一浏览器、同一地址及端口。测试预览使用 5173，启动文件使用 4173，两者的浏览器存储独立。

当前版本以 package.json 和 src/version-v0.3.4-2026.10.21.ts 为准；其他带旧版本或日期的组件、说明与测试为沿用文件。

## 开发

GitHub 源码不包含 dist 和 node_modules。从仓库克隆后，先安装依赖并运行构建，再使用启动文件。

```sh
npm install
npm test
npm run build
npm run dev
```

浏览器检查使用 `npm run test:browser`，默认连接 http://127.0.0.1:5173/ 。
