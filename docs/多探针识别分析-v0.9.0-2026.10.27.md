# 多探针识别分析 · v0.9.0 · 2026.10.27

本模块接入现有导航、Worksheet、工作簿及浏览器持久化框架。每个输入 Sheet 独立保存探针、测定强度、批次空白和图形设置。原始光谱、对象筛选、校准与浓度梯度继续使用各自的工作簿。

本次开发分支为 `feature/v0.9.0`，代码保留在本地，未推送、合并或部署。

## 使用步骤

1. 双击项目根目录的 `打开前端-v0.9.0-2026.10.27.command`，或运行 `npm run dev`。在左侧打开「多探针识别分析」，路由为 `#recognition`。
2. 在「探针管理与空白批次」添加、重命名、排序或选择探针，并设置探针颜色。名称可包含中文和离子上下标。探针使用内部稳定 ID，排序与改名不移动其测量值。
3. 切换「空白与批次」，填写每个批次、每个探针的 F₀。添加其他批次后分别填值。批次名称须唯一且非空；已被实验行引用的批次须先重新映射才能删除。
4. 切换「原始强度」，按以下列顺序录入或从 Excel 粘贴：样本 ID、离子种类、平行编号、批次名称、探针 1 F、探针 2 F……。一个样本的不同平行实验保留为独立行，同一样本 ID 与平行编号的组合须唯一。每行的全部探针必须来自匹配的同一次实验。
5. 在「猝灭率」查看只读 q 和 Q。选择预处理方式及聚类数或截断高度。完整、有效的数据会自动生成分析结果；无效单元格以红色标记，并在提示中列出表名、单元格地址及原因。点击提示可定位。
6. 在数据视图查看 PCA 得分、探针载荷、解释率、累计解释率、簇编号和分析设置。在图形区切换 PCA 得分图、载荷图、树状图和带树状图的响应热图。
7. 点击「导出分析 Excel」保存完整工作簿。各图支持 SVG、PNG；共用原有图表设置中的标题、轴名、字体、图例、图宽及分辨率。
8. 在结果视图点击「保存当前结果到新 Sheet」生成只读快照。快照注明来源与保存时间；来源数据变化后会提示重新分析，原始 Sheet 保留。

「载入演示数据」只替换当前多探针输入 Sheet，并明确标记为人工生成的演示数据。数值与结构修改均可通过工作表工具栏或快捷键撤销、重做；历史保留最近 20 次操作，刷新后从持久化数据重新计算。

## 计算定义

- q = (F₀ − F) / F₀；Q = q × 100%。F₀ 必须为有限正数，F 必须为有限数值。空值不按零处理，F > F₀ 时保留负 q。F 与 F₀ 以原始字符串独立保存，数值计算与 Excel 导出使用完整浮点精度，仅页面显示按所选小数位舍入。
- 默认预处理为中心化＋Z-score。Z-score 使用每个所选探针的**样本标准差（ddof=1）**；「仅中心化」仅减去列均值。每行平行实验独立进入矩阵，离子标签、样本 ID、平行编号及颜色不进入数值特征。
- PCA 使用对称 Jacobi 特征分解计算预处理矩阵的样本协方差矩阵。载荷为单位特征向量，得分 = 预处理矩阵 × 载荷，解释率 = 特征值 / 总方差。符号选择只用于稳定显示；等价结果允许得分与载荷同时反号。[PCA 定义参考](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)。
- 聚类固定使用**完整所选探针响应矩阵**，与 PCA 采用相同预处理，再计算欧氏距离与 Ward 连接；使用 Ward 距离更新递推式。[Ward 定义参考](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html)。不使用 PC1、PC2 替代完整矩阵。
- 支持按准确簇数或有限非负高度截断。簇编号按样本顺序稳定分配，其编号本身不具有科学含义。距离相同时按节点顺序确定合并顺序。
- 热图可显示原始 q 或 Z-score（ddof=1）。色阶对称于零，正负值均保留。行树顺序由层次聚类确定；样本标签和数值使用相同的原始行索引，列顺序与当前探针选择和排序一致。
- 离子、探针、聚类、热图色阶使用四套独立配置。样式修改不重新运行数值算法；样本或批次标签变化会重新校验对应关系，标签不作为特征。数据或计算设置失效时，清除当前派生图表与结果，不继续展示旧结果。

数据不足、所选探针少于 2、零方差列或数值溢出会阻止分析。只有 1 个有效主成分时保留 PC1 数值表与有效聚类，提示无法绘制二维 PCA 图，不生成 PC2。秩不足时只输出实际有效的主成分。

## 保存与导出

沿用 `perovskite-lab-workspace-v1` 本地存储键、现有 500 ms 自动保存及存储失败提示。工作簿状态仍使用兼容性 schema `1`；这是数据格式编号。旧工作区缺少多探针字段时补充空白模块，不改变旧分析数据。

Excel 包含 9 个 Sheet：

| Sheet | 内容 |
| --- | --- |
| 原始强度 | 实验标签、批次映射、行 ID、原始 F |
| 空白与批次 | 稳定批次 ID、名称、各探针 F₀ |
| 猝灭率 | 完整精度的 q 与 Q (%) |
| PCA得分 | 每行实验的所有有效主成分得分 |
| PCA载荷 | 探针名称、稳定 ID、全部有效载荷 |
| 方差解释率 | 特征值、解释率、累计解释率 |
| 聚类结果 | 实验标签、行 ID、簇编号 |
| Ward合并 | 合并节点、距离、样本数，可与 SciPy linkage 核对 |
| 分析设置 | 软件版本、数据来源、公式、预处理、均值与缩放、探针 ID、选择、截断方式及完整样式 JSON |

数值表、结果快照与 Excel 共用同一个结果转换函数。图形导出复用现有内置字体与 PNG 栅格化流程，支持中文、Fe³⁺、CO₃²⁻ 等字符。导出文件名含 `v0.9.0` 和 `YYYY.M.D` 日期。

当前每个输入 Sheet 最多分析 **500 行、24 个探针**，每个模块沿用最多 20 个 Sheet。SVG 适合较多样本；PNG 沿用现有导出像素上限，尺寸过大时会明确提示减小图宽。

核心参考矩阵为：

```text
0.74   0.19  0.35
0.71   0.21  0.38
0.17   0.76  0.30
0.20   0.72  0.33
-0.21  0.10  0.78
-0.18  0.13  0.75
```

参考文件由本机 NumPy 2.4.6、SciPy 1.17.1 独立计算，核对方式如下：

```python
import numpy as np
from scipy.cluster.hierarchy import linkage, cut_tree
q = np.array([[.74,.19,.35],[.71,.21,.38],[.17,.76,.30],
              [.20,.72,.33],[-.21,.10,.78],[-.18,.13,.75]])
x = q - q.mean(axis=0)
# Z-score 模式再执行：x /= q.std(axis=0, ddof=1)
u, singular, vt = np.linalg.svd(x, full_matrices=False)
eigenvalues = singular**2 / (len(q) - 1)
explained = eigenvalues / eigenvalues.sum()
scores, loadings = u * singular, vt.T
merges = linkage(x, method='ward', metric='euclidean')
clusters = cut_tree(merges, n_clusters=3)
```

两种预处理均检查解释率、特征值、得分、载荷、矩阵重构、Ward 合并距离与分组；比较前对齐 PCA 符号，聚类使用成对同簇关系比较，允许簇编号不同。测试还确认完整矩阵的 Ward 距离与只用前两个 PC 的距离不同。

仅中心化时解释率为 66.011666%、33.958385%、0.029949%；Z-score 时为 67.446934%、32.508325%、0.044742%。F₀=1000、F=260 得到 q=0.74、Q=74%；F=1210 得到 q=−0.21、Q=−21%。缺失值、非数值、F₀≤0、零方差、秩不足、错误截断参数、探针重排、独立平行实验及标签不参与计算均有测试。
