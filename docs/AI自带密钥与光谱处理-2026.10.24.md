# AI 自带密钥与光谱处理（2026.10.24）

开发分支：`develop/v0.7.0`。项目版本 v0.7.0；从 `feature/v0.6.0` 整理升级。

## 使用方式

1. 双击根目录 `打开前端-v0.7.0-2026.10.24.command`。原有 v0.6.0 启动入口兼容转到此脚本。需要 Node.js 20.19+ 或 22.12+ 和项目依赖。
2. 在光谱工作台导入一个或多个 TXT，确认列映射。也可在原始表格输入数据并点击“根据表格绘图”。
3. 在图表下方的“AI 辅助光谱处理”选择 DeepSeek 或 OpenAI、模型，并填写自己的 API Key。
4. 确认激发波长、溶剂/基质、可选目标保护区和空白参考。空白不能同时作为待处理样品，需人工确认测量条件一致。
5. 勾选数据发送与个人账户计费说明后，可以测试连接或请求分析。只有点击测试或分析才调用模型；不会自动重试付费请求。
6. AI 区间默认未勾选。逐项核验，可修改边界和理由，也可自行添加区间。没有密钥或 API 不可用时，手动处理仍可使用。
7. 点击“预览处理”，查看灰色原始曲线、彩色处理曲线和红色排除点。检查后点击“确认应用处理”，再导出 Excel。

默认按当前 sheet 中的可见光谱选择样品；单次 AI 请求最多 8 条样品、12000 个数据点（含空白），请求体最多 900000 字节。超限明确提示分批，绝不静默抽稀。调整数据、样品选择或测量条件后清除建议；修改处理区间后原预览和导出立即失效。切换 sheet 清除当前处理结果，AI 密钥按服务商独立保存在当前浏览器中。

## 处理范围与 Excel

- 区间排除保留波长行，处理强度留空；预览按连续有效区间分段，不跨缺口连线。
- 保护区禁止排除；区间必须在测量范围内且包含测量点。
- 空白按 1:1 扣除，波长不同时只在空白实测范围内线性插值；不外推，不把负值截为零。
- 处理结果作为独立快照，不覆盖原始工作表，也不自动送入对象筛选、校准或浓度计算。
- 不通过平滑或模型补值恢复重叠目标峰。无法确认的真实峰应保留，必要时补测空白或改变激发条件。
- Excel 包含“原始数据、处理数据、修改记录、处理参数”四张可编辑表；包括原始样品、所选空白、原值/处理值、排除标记、方法、参数、来源、模型和分析说明。
- 文件名使用北京时间 `YYYY.M.D`，例如 `光谱干扰处理-v0.7.0-2026.10.24.xlsx`。
- 处理建议和结果目前仅保留在此面板内存中，请及时导出 Excel；刷新页面后重新处理。

## 费用、数据与凭据

模型费用由用户填写的 API Key 所属账户承担。站点未配置开发者密钥回退；余额不足、限流或鉴权失败时返回提示，由用户自行决定是否重试。Cloudflare 转发仍有基础设施用量，按站点套餐计费。

按用户要求，API Key 自动按服务商持久保存在当前浏览器的独立 localStorage 记录 `perovskite-lab-ai-credentials-v1` 中，刷新、关闭后重新打开、切换服务商、切换工作表或新建空白工作区均不主动删除密钥。每家服务商的密钥和模型分别保存，切回时自动恢复；密钥不进入 sessionStorage、工作区、JSON 备份或 Excel。默认不自动发起模型调用，重新打开后仍需确认数据发送与计费说明。

“清除密钥”只删除当前服务商密钥；“清除全部服务商密钥”删除本机所有已保存的服务商密钥。多个同源标签页会同步更新，避免旧标签页重新保存已清除的密钥。读取损坏设置或写入失败时显示提示；保存失败时不声称已永久保存。

本地存储为明文，本站页面脚本可以读取；请求时密钥经本站后端临时转发，但服务器不持久保存。密钥保留范围限同一浏览器、浏览器配置和网站来源（协议、域名、端口）；不同设备/浏览器/网址不共享。清除网站数据、浏览器清理或无痕会话结束可能删除保存内容，因此不能承诺浏览器环境变化后仍永久保留。

用户同意并点击分析后，所选完整光谱的波长/强度、名称、激发波长、溶剂/基质、保护区和所选空白经 HTTPS 发送至本站临时转发接口，再发往所选模型服务商。测试连接只发送最小测试提示，不发送光谱。服务商自身的数据处理政策适用于其收到的数据。

接口使用用户请求头中的凭据，仅转发至代码内固定的官方地址；禁止任意自定义 URL，禁止跟随重定向，不将 Cookie 或其他浏览器请求头转给模型。服务器无密钥数据库、密钥环境变量或凭据日志。API 响应 `Cache-Control: no-store`；错误提示不回显模型原始错误、请求体或 Authorization。部署运维时也应避免添加请求头/请求体日志和调试采集。

## 技术接入

- 前端：`src/components/AiSpectraPanel-2026.10.24.tsx`；凭据上下文与独立本地持久化 `src/state/ai-session-2026.10.24.tsx`。
- 协议和白名单：`shared/ai-contract-2026.10.24.ts`。
- 共用后端：`server/ai-handler-2026.10.24.ts`，接口 `POST /api/ai/test` 和 `POST /api/ai/analyze`。
- DeepSeek：`deepseek-flash` / `deepseek-v4-pro`，Chat Completions JSON 模式，显式关闭思考模式以约束输出用量。
- OpenAI：`gpt-6.1-sol` / `gpt-6-luna`，Chat Completions JSON 模式、低推理强度，限制输出 token；使用独立参数适配。
- 本地：Vite 插件把同一个后端挂载到开发和 preview 服务。`npm run dev` 默认 5173；`npm run preview -- --host 127.0.0.1 --port 4173 --strictPort` 使用构建后的网页及相同后端。
- Cloudflare：`wrangler.jsonc` 增加 Worker 入口、ASSETS 绑定和 `/api/*` 优先路由。前端资源和 API 同域。部署此版本时需同时包含 Worker，不能只上传 dist。
- 旧 Python 静态服务器仍可查看普通功能，但不能提供 AI 接口。使用上述新入口；使用同一地址和端口可保留原浏览器工作区。
- 后端校验输入规模、测量点顺序、服务商和模型；限制上游响应大小与约 55 秒超时；前端约 60 秒超时，支持取消。取消不能保证服务商立即停止计算或免除已产生的费用。
- 模型返回后再次验证 JSON、光谱 ID、区间边界和测量点。未知字段不会被当作可执行指令。修改数据时取消旧请求并丢弃迟到响应。
