# 多探针图表优化 · v0.9.2 · 2026.10.29

开发分支：`feature/v0.9.2`。本次修改保存在本地工作区。

## 使用

双击项目根目录的 `打开前端-v0.9.2-2026.10.29.command`，或运行 `npm run dev`，打开 `/#recognition`。

- 在「图形与颜色」选择「PCA 得分图」或「层次聚类树状图」单独查看。
- 选择「PCA + 聚类双图」，桌面端左右排列，窄屏上下排列；手机可在图内横向滑动。
- 「离子颜色」「离子散点形状」分别设置每种离子的颜色与形状；未单独设置的形状跟随「样本点形状」。
- 默认配色在超过八种离子时继续生成不同颜色，不再循环使用原有八色；自定义颜色优先。
- 每张图保留自己的标题、坐标设置、导出宽度、DPI 和 PNG / SVG 下载按钮。PCA 得分图与树状图共享字体、字号与线宽设置。

## 绘图规则

PCA 得分图删除离子图例和逐样本标签，直接在每组附近放置一个离子化学式。标签按宽度排序后寻找空白位置，避让全部散点及已放置的标签；空间不足时扩大 SVG 画布，保持原始坐标。较远的标签使用细引导线关联本组散点。坐标轴保留真实得分和解释方差，只显示左、下坐标轴，背景为白色，无网格。

化学式通过 SVG `tspan` 排版上下标和电荷，支持 `Fe³⁺`、`CO₃²⁻`、`Fe3+`、`CO3^2-`、`SO4^{2-}` 等写法。输入时遇到多原子离子的电荷歧义，可使用 Unicode 或显式 `^` 电荷。自由文字保持原样并进行 XML 转义。

水平树状图在左侧按原有树的叶节点顺序显示每行离子的化学式，零距离在左，真实 Ward 合并高度向右增加。全部平行实验分别保留，包含高度为零的重复样本合并。树枝为细深灰线，删除簇图例；样本 ID、离子、平行编号和簇保留在悬停提示中。叶节点间距随字号和样本数增加。

## 数据与兼容

PCA、预处理、Ward、树的叶节点顺序和截断算法保持原实现；颜色、形状、字体和布局不进入计算指纹。没有平均、删点、补零、抖动或重新聚类。

载荷图、热图及其颜色和图例继续使用原有绘制流程。单图和双图使用同一份 SVG 作为预览与下载来源，PNG 使用现有字体嵌入和栅格化流程。没有新增图表依赖。

旧工作区首次升级时，以原有 PCA 得分图的字体和字号统一两图；原先默认的 2.4 线宽调整为 1.1。各图标题、颜色、坐标范围、导出参数和全部实验数据保留。

应用、工作表界面、HTML 标题、导出版本及启动脚本统一为 `v0.9.2`。按用户确认，保留已有源码和测试文件名，以及历史文档、截图和兼容入口。
