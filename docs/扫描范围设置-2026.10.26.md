# 上传后的扫描范围设置

日期：2026.10.26。分支：`feat/v0.8.1`。

上传 TXT/CSV 后，在“文件识别摘要”下方修改“扫描范围起点 / nm”和“扫描范围终点 / nm”，点击“按扫描范围生成预览”，核对后确认处理结果，再导出或同步 Sheet。

- 默认显示完整测量范围，每个文件独立保存设置。
- 范围为 nm 闭区间；禁止空值、逆序、越界及少于 5 个实际测量点。
- Hampel/MAD、空白扣除及主峰检测仅使用所选范围内的测量点。原有质量检查和保护区规则继续适用。
- 处理后 Excel 和 Sheet 仅包含所选范围内的数据；原始表仍包含全部测量值、源行号。
- 修改范围后旧确认、旧模型操作和旧导出资格失效，需重新生成并确认。
- “恢复完整范围”可恢复所有原始点的处理范围；已确认的人工编辑仍按现有重放规则保留。
- AI 上下文区分完整测量范围和所选处理范围，批量编辑不能越出当前处理范围。
- Excel 参数表记录范围，修改记录列出范围外保留的原始点。

验收：101 点、450–550 nm 的样品选取 480–540 nm 后，处理后导出 61 点，原始表保留 101 点；恢复完整范围后重新导出 101 点。Excel 与 Sheet 数值一致，桌面及 390px 手机布局已检查。

验证结果：`npm test` 224 项通过；`npm run build` 通过；`npm run test:browser` 95 项通过。新增 14 项单元测试、2 项浏览器测试。构建仍有既有字体模块体积提示。
