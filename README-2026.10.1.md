## 直接使用

macOS 双击 **启动网页-2026.10.1.command**。它使用本机 Python 3 启动已构建网页并打开浏览器，默认地址为 `http://127.0.0.1:4173/`。无需安装前端开发依赖。使用期间保留终端窗口，关闭服务按 Ctrl+C。

如果系统拦截双击，可在终端进入项目目录，执行：

```sh
zsh 启动网页-2026.10.1.command
```

任意安装 Python 3 的系统也可执行：

```sh
python3 启动服务-2026.10.1.py
```

不要直接双击 `dist/index.html`：浏览器的本地文件限制会影响模块与导出字体加载。

## 第一版功能

- XLSX / XLS / CSV / TXT 导入：多文件队列、工作表选择、数据预览、列映射、起始行、无表头数据、UTF-8 / GBK、自动或指定分隔符。
- 光谱宽表和长表、单/多光谱、可见性与顺序、归一化、峰位/Fmax/FWHM/测量范围积分；在指定波长插值提取筛选或校准数据。
- 任意分析对象名称、角色、浓度、单位、强度与备注；添加、编辑、删除、拖动与按钮排序；明确指定空白和目标物。
- F、F/F₀、F₀/F、(F₀−F)/F₀、猝灭率响应及筛选柱状图。
- 选择拟合点与范围，普通最小二乘线性拟合、方程、R²、残差；统一浓度单位。
- LOD（3 或 3.3σ/|k|）与 LOQ（10σ/|k|）；σ 来自空白重复测量或手动输入，始终使用同一响应尺度。
- 母液独立稀释的浓度梯度，扣除量子点/缓冲液等固定添加体积，导出 Excel 配液表。
- 图表标题、坐标名称与范围、字体字号、颜色、线宽、数据点、虚线、网格、图例；PNG（300 / 600 dpi）、SVG、矢量 PDF，以及数据 Excel 导出。
- 浏览器本地自动保存与 JSON 数据备份下载。实验记录、项目和文献数据库只预留接口。

卤素交换计算未实现。

## 建议体验顺序

1. 先用载入示例体验四个页面。示例为人工生成，不代表实验结果。
2. 导入自己的文件。首次导入会清除整个示例工作区，避免真实数据与示例混用；后续导入追加真实数据。
3. 对光谱设置名称、角色、浓度和单位。校准光谱应标记为目标物或空白。
4. 从光谱提取指定波长数据，或直接导入名称–强度/浓度–强度表。
5. 明确空白参考 F₀、拟合范围及空白重复测量，再查看结果并导出。

`examples/` 提供带日期的可导入示例。单个文件上限 20 MB，单条曲线上限 100000 点。无效记录会统计并提示；重复波长拒绝导入该曲线。TXT 的仪器说明行可通过起始行跳过；波长目前按 nm 处理。

CSV 格式、报错排查与 2026.10.1 的兼容修复见 [CSV 导入说明](docs/CSV导入说明-2026.10.1.md)。导入窗口可查看格式并下载当前布局模板，常见列名及起始行会自动建议，仍需对照预览确认。

## 保存与导出

实验文件在浏览器内读取，运行时没有远程上传或在线库请求。工作区存储与浏览器及网页来源绑定；更换浏览器或端口会产生不同的本地存储。JSON 下载是可读的完整工作区备份，本期未提供 JSON 恢复按钮。请不要把浏览器存储作为唯一的原始数据副本。

PNG 用物理宽度和 dpi 计算像素，并写入 pHYs 分辨率。SVG 在需要中文/科学字符时嵌入开源字体，支持离线打开。PDF 完整嵌入内置字体以保证阅读器兼容，通常约数 MB；文字和曲线保持矢量。PDF 使用内置字体，与所选 Arial / Times 的字形可能略有差别。

窄屏图表可左右滑动，以保持坐标文字可读；表格也可横向滚动。

## 后续开发

使用 Node.js 20.19+ 或 22.12+，建议 Node.js 22 LTS。项目使用 pnpm 并附锁文件。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

若使用 npm，也可 `npm install`、`npm run dev`；这会生成 npm 自己的锁文件。本次交付保留 pnpm 锁文件中的已验证版本。

浏览器测试：先启动 `pnpm dev`，另开终端运行 `pnpm test:browser`。macOS 测试配置默认使用已安装的 Chrome；其他系统先运行 `pnpm exec playwright install chromium`。可通过 `LAB_URL` 指定构建后的预览地址。

```text
src/
  components/   导入弹窗、图表设置、共用表单
  domain/       数据类型、计算、SVG 绘图纯函数
  features/     光谱、筛选、校准、浓度梯度页面
  services/     导入、导出、下载、未来仓储接口
  state/        本地工作区与示例
tests/          数值/导入测试和浏览器流程测试
docs/           技术方案、验收记录
dist/           可直接由静态服务器提供的构建结果
```

从 `src/services/contracts.ts` 接入后续 `Experiment`、`Project` 和 `Literature` 存储适配器。导入大文件的后续优化可移入 Web Worker；不要改动 `domain/` 的响应尺度与单位约定。

可选浏览器 WebMCP 接口位于 `useLabTools.ts`，仅在浏览器提供该实验性标准时注册；普通浏览器不受影响。本期不包含账号、后端、云同步或实验记录存储。

计算依据与完整约定见 `docs/技术方案与页面架构-2026.9.30.md`；验证结果见 `docs/验证记录-2026.10.1.md`。
