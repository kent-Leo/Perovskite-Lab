# Perovskite Lab v1.2.0 — 分组柱状图

日期：2026.11.6；开发分支：`feature/v1.2.0-grouped-bar`。

## 使用方法

1. 在「对象筛选」的「绘图类型」中选择「分组柱状图」。原有单系列对象、强度及响应计算单独保留，可以随时切回。
2. 第一列填写对象名称，其余列填写各实验系列。可以直接粘贴 Excel 区域，或导入 XLSX / CSV：选取文件中的工作表、是否有表头及数值类型后，会创建新 Sheet。
3. 「直接输入统计结果」主表录入平均值；选择 SD、SEM 或手动误差后，在下方误差表填写非负误差值。三种误差分别保存。
4. 「输入重复测量」每个单元格用分号分隔重复值，例如 `10;12;;14`。逗号、中英文分号也支持；空项保留但不参与统计，不能用千位逗号表示一个数值。切换输入方式不会覆盖另一方式的数据。
5. 系列可新增、改名、配色、隐藏、上下移动；右键行号 / 列标可以插入或删除分类及系列列。使用现有工作表拖动选区、区域复制粘贴和撤销重做。名称列受保护，至少保留一个系列，沿用工作表的 64 列上限（最多 63 个系列）。
6. 在图表设置中调整柱宽、组内 / 组间间距、连续垂直渐变、边框、误差棒、标签角度、网格线和数值标签。图例支持顶部、底部、右侧、自由拖动以及独立字体字号；坐标轴和中西文字体沿用现有设置。
7. 图表和 Excel 数据独立导出。PNG 提供 300 / 600 dpi，宽度由 cm 设置决定；SVG 与 PDF 保留柱体、连续渐变和误差棒为矢量。系统字体的开源替代规则沿用现有字体导出说明。

## 统计约定

- 空单元格不绘制柱体；有效数值 `0` 保留。正值、负值均从零基线绘制。
- 重复测量使用算术平均值、样本标准差 `SD = √(Σ(x−Mean)²/(n−1))` 及 `SEM = SD/√n`。
- `n < 2` 时 SD / SEM 为空；不会伪造零误差。直接输入统计结果时 n 未知。
- 非空非法数值会给出对象 / 系列位置，不能静默跳过。误差上下端点为 Mean ± error，自动 Y 范围包含端点；手动轴范围会按用户指定范围裁剪。
- Excel 包含当前宽表、统计结果、逐个原始重复测量、手工输入的 Mean / SD / SEM / 误差以及系列设置。隐藏系列仍保留于数据导出，并用显隐字段注明；空数值保留为空。

## v1.2.0 更新日志

- 新增独立的分组数据模型，不使用 `ObjectRow.intensity` 存储多系列数值。
- 分类、系列稳定 ID、原始输入、误差与绘图样式随筛选 Sheet 独立保存；全部 Sheet 画廊使用各自数据与样式。
- 新增分组布局、缺失值留空、SD / SEM / 手动误差棒、系列图例、标签角度与独立图例字体。
- 复用 Worksheet、ChartPanel、工作簿与导出服务；新增 CSV / XLSX 宽表导入及多工作表 Excel 导出。
- SVG 使用连续渐变；PDF 通过矢量轴向渐变保留相同填充，补齐柱边框和独立图例字体。
- `.plab` 保存并恢复所有分组字段；旧项目没有新字段时使用单系列模式。`Workspace.version` 与项目格式版本仍为 `1`，仅应用版本升级为 `1.2.0`。
- 更新应用、HTML 入口及本地启动器版本；发布打包文件名沿用 `electron-builder.yml` 的 `${version}`。
