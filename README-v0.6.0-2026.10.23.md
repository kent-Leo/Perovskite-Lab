# Perovskite Lab v0.6.0（2026.10.23）

双击本目录的 `打开前端-v0.6.0-2026.10.23.command`，即可使用已构建的网页。默认地址为 http://127.0.0.1:4173/ 。如旧服务占用端口，先在旧服务终端按 Ctrl+C，再启动本版。

## 本版新增（v0.6.0）

### 1. 修复 Windows 下输入数据后不能拖动选中表格

在 Windows 的 Chrome / Edge 中，点击单元格输入数据后再从该格按下鼠标拖动，原先无法拖出选区。原因是输入框在聚焦并全选文字后，按下拖动会被浏览器当成原生文本拖放，指针事件流被取消，拖拽框选随之失效。

现在单元格按下时取消原生文本拖选/拖放，再由工作表组件手动聚焦并全选文字，保留「点击即全选、直接键入替换」的习惯；单元格输入同时禁止成为拖放源，工作表拦截来自单元格的 `dragstart`。下拉、勾选、颜色、行内操作按钮与行号拖动排序不受影响。

### 2. 修复 Windows 版本不能快速选中表格

拖拽期间增加窗口级指针兜底：用 `document.elementFromPoint` 命中当前表格的单元格并扩展选区。即使快速拖动（一次移动跨多格）、指针短暂离开表格再回来，也能选中包含起点与终点的完整矩形。Shift+点击、Shift+方向键、⌘/Ctrl+A 全选等既有方式保持不变。

> 说明：Windows 浏览器原生拖放无法在 macOS 自动化环境中复现，本轮用「`dragstart` 被阻止 + 快速/越界拖动选区正确」的浏览器回归测试验证修复机制；正式发布前建议在 Windows 真机 Chrome / Edge 再手工回归一次。

### 3. 每个 sheet 的图表标题独立（标题中不带 sheet 名）

- 图表设置中的「图表标题」改为**按 sheet 独立保存**：在某个 sheet 上输入标题只影响该 sheet，其他 sheet 保持各自标题；切换 sheet 时标题随之恢复。
- 图表标题**不会追加 sheet 名**。标题留空时使用页面默认标题（`荧光光谱`、`分析对象筛选`、`浓度–响应校准曲线`），输入后图表头部、图内 SVG 标题与 PNG / SVG / PDF 导出都使用该 sheet 自己的标题。
- 新建 sheet 从页面默认标题开始，不会继承其他 sheet 的自定义标题；重命名 sheet 不改变图表标题。
- 「全部 sheet」画廊中的每张图表卡片使用各自 sheet 的标题（卡片标题仍显示 sheet 名，便于区分）。
- 旧工作区中曾共享的图表标题（`styles[kind].title`）会在升级时一次性写入该页每个 sheet 的独立标题并清空旧字段，之后各 sheet 可分别修改。

### 4. 新功能：在图中显示数据点数值

- 三个绘图页的「图表设置 → 外观」新增 **显示数据点数值** 复选框；勾选后当前图表立即在每个数据点旁显示对应的 y 值。
- 折线/散点数值优先放在点上方，贴近绘图区顶部时自动放下方，并在左右边缘调整对齐；柱状图数值在柱顶上方，负值在柱底下方。
- 校准曲线只标注「测量值」数据点，不标注线性拟合线端点。
- 数值随 SVG / PNG / PDF 导出，字号约为图表字号的 0.75 倍（最小 9），不进入图例或坐标轴文本。
- 勾选状态随图表样式保存在当前浏览器，切 sheet、切页面、刷新后保持；旧工作区默认关闭。

详细原理、实现位置与限制见 [表格拖拽框选、每 sheet 图表标题与数据点数值](docs/表格拖拽框选与图表标题数值-2026.10.23.md)。

## 兼容与迁移

- 浏览器存储键 `perovskite-lab-workspace-v1` 不变，v0.5.5 及更早工作区自动升级；表格数据、sheet 列表、列头元数据、已绘制曲线与图表样式继续保留。
- 图表样式新增可选字段 `pointValues`（默认关闭）与 `Series.showPointValues`；旧工作区无需迁移，读取时按默认值补全。
- 每 sheet 图表标题保存在 `workbooks[page].tabs[].chartTitle`；旧工作区共享的 `styles[kind].title` 会自动写入该页每个 sheet 并清空旧字段，因此升级后标题仍可见且可分别修改。
- 恢复原工作区需要使用同一浏览器、同一地址及端口。测试预览使用 5173，启动文件使用 4173，两者的浏览器存储独立。
- 当前版本以 package.json 和 src/version-v0.6.0-2026.10.23.ts 为准；其他带旧版本或日期的组件、说明与测试为沿用文件。

## 开发

GitHub 源码不包含 dist 和 node_modules。从仓库克隆后，先安装依赖并运行构建，再使用启动文件。

```sh
npm install
npm test
npm run build
npm run dev
```

浏览器检查使用 `npm run test:browser`，默认连接 http://127.0.0.1:5173/ 。
