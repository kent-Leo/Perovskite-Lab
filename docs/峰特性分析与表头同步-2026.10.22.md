# 峰特性分析与原始光谱表头同步（v0.4.3 引入，2026.10.22）

## 原始光谱表头成为图例与外观的唯一来源

- 每列上方的「名称 / 单位 / 备注」三行现在会持久化到工作区；新增「颜色」行。
- 图例文字按「备注 → 名称 → 绘图时的名称」取值，修改表头后图例立即更新。
- 颜色行直接控制曲线颜色；绘图后修改颜色也会同步，不需要重新绘图。
- 「名称 / 单位 / 备注」输入框单击即全选，可直接覆盖输入；也可粘贴一行制表符分隔值，或一列纵向值，按列横向填入。
- 「第 N 列作为强度」复选框同时控制绘图列和曲线显示；取消勾选后曲线立即隐藏，重新勾选后恢复。

## 样品分析区域

「样品与分析对象」工作表已移除。曲线名称、备注和颜色改由原始光谱表头统一管理；角色、浓度等后续分析字段不再在光谱页重复录入。旧工作区中的样品信息仍保留在浏览器存储中，不影响载入。

## 峰特性分析模块

原「从光谱提取检测数据」面板替换为峰特性分析，包含：

| 指标 | 定义 |
|---|---|
| 峰位 λmax | 当前查看光谱的最大强度对应波长 |
| 峰强度 Fmax | 最大强度 |
| 半高宽 FWHM | 零基线主峰两侧半高交点插值宽度，不覆盖时为 — |
| 斯托克斯位移 | 峰位 − 激发波长；激发波长需手动输入，留空或非正数时为 — |
| 峰面积 | 当前光谱测量范围内原始强度的梯形积分，单位 a.u.·nm |

- 「当前查看光谱」切换分析对象；指标始终使用原始强度，归一化仅影响绘图。
- 「导出峰指标」导出所有当前显示光谱的峰位、峰强度、FWHM、斯托克斯位移、峰面积和积分区间。
- 积分区间显示在面板底部，例如 `500–520 nm`。

## 数据兼容

- 新增 `rawColumnSpectra` 保存原始光谱列与已绘制光谱的对应关系，刷新或重新绘图时复用同一条曲线，避免重复。
- 新增 `excitation` 保存激发波长；旧工作区没有该字段时显示为空。
- 旧工作区中的 `spectra`、`rawSpectra`、`objects`、`calibration` 与样式设置继续兼容。

## 验证

`pnpm test`：66 项单元测试通过。`pnpm test:browser`：47 项浏览器测试通过，覆盖表头快捷粘贴与全选、备注决定图例、颜色同步、强度列显隐、峰指标计算与导出、刷新恢复及手机布局。
