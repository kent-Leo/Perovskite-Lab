# AI 批量光谱编辑 v0.8.1

日期：2026.10.26。开发基线：`origin/main` 的 `24d245e`；开发分支：`feat/v0.8.1`。

一次上传 A.TXT、B.TXT、C.TXT 后，选择三份文件，在对话中输入“删除所有文件 350–400 nm 的数据并合并导出 Excel”。模型返回受限计划，点击“应用建议并生成预览”，逐文件核对影响行数和前后值，再勾选确认并点击“确认批量编辑”。最后点击“统一导出 Excel”。

本次三样品验收中，每份光谱有 301 个测量点，范围为 300–600 nm，步长为 1 nm。闭区间 350–400 nm 每份删除 51 行；合并处理后表共 750 行，合并原始表完整保留 903 行。Excel 与三个网站 Sheet 的波长、处理后数值逐项一致。

## 编辑规则与审计

| 操作 | 行为 |
| --- | --- |
| `delete-range` | 删除闭区间内的处理后数据行；原始测量数据及源行号保留 |
| `mask-range` | 保留波长行，处理后强度留空；不会用零值替代空缺 |
| `keep-range` | 仅保留闭区间内的处理后数据行 |
| `set-point` | 修改精确匹配的现有测量点的处理后强度；不插值、不新增波长、不改原始强度 |
| `offset` | 对区间内非空处理后强度加指定常数 |
| `scale` | 对区间内非空处理后强度乘指定系数 |
| `normalize` | 按区间内最大绝对强度缩放至正数 `target`，保留正负号；零值或全屏蔽区间拒绝 |

所有范围以 nm 为单位，包含两个端点。区间必须落在每份文件的实际测量范围内；没有可用测量点、指定波长不存在或已删除、数值溢出、类型错误、越权文件、版本失效均拒绝整批。算术操作保持已有屏蔽空值。

每一步按顺序作用于全部所选文件。每份原始数据保留在独立测量字段中，删除通过处理层的行状态记录。审计包含文件 ID、批次、操作序号、类型、理由、波长、源行号、原始测量值、前后值及前后删除状态。撤销追加反向审计，重新应用会再次生成预览。

主峰保护区、算法主峰以及原始最大值发生变化时，预览给出风险行数，必须另行勾选主峰风险授权。模型无法提交权限开关、代码或任意强度数组。

## 版本与数据流

`shared/ai-chat-2026.10.25.ts` 对 `update-parameters` / `batch-edit` 使用判别联合及严格运行时校验。上下文包含所选文件 ID、文件名、实际范围、原始点数、当前版本、预览状态、剩余/删除/屏蔽数量、原始及处理后最大值。大文件仍使用最多 384 个真实测量点供模型参考；编辑引擎只使用本地全量数据。

`src/domain/assistant-batch-edit.ts` 将人工编辑与已有 Hampel/MAD、主峰保护、空白扣除算法分离。预览为不可变计算；确认时重新检查完整本地数据与计划指纹。文件、参数、编辑计划、数据变动均影响版本，撤销也生成新版本，旧计划不能复活。异步模型回复在文件版本或选择变化后失效。

基础参数重新计算时，在新算法结果上重放仍有效的人工计划，并记录重放审计；失败保留上一份完整数据与审计，禁止确认过期结果。界面支持撤销最近一次批量提交，随后重新应用仍需预览和确认；目标文件版本已变化时拒绝旧撤销。

正式结果仅在二次确认后写入。默认同步为整批先构建所有 Sheet 修改，再一次更新工作区；构建任一 Sheet 失败时不提交本批次。已同步的文件在撤销/重新应用时更新同一 Sheet。既有单文件导出、对话、算法参数和 Sheet 功能保留。

## XLSX 结构

- `汇总_处理后`：全部所选样品的已确认处理后长表，删除行不出现，屏蔽行强度为空。
- `汇总_原始`：完整原始测量值及源行号。
- 每文件明细：原始值、原始文本行、处理后值、删除/屏蔽状态及理由。
- `修改记录`：基础算法异常记录及人工编辑、撤销、重放审计。
- `处理参数`：逐文件仪器元数据、算法参数、质量检查、编辑计划、软件版本与导出日期。

文件 ID 区分同名样品。工作表名称清除 Excel 非法字符、限制在 31 个字符以内并处理大小写重名。每张工作表最多 1,048,576 行，超过限制自动分表且保留表头；长文本拆为续列或分段记录。单文件四表导出也保留批量编辑审计。

继续沿用单文件 20 MB、最多 20 个上传文件的已有约束。网站工作区仍遵循原有 Sheet 数量限制；容量不足会拒绝同步提交，可关闭自动同步后确认并导出 Excel。
