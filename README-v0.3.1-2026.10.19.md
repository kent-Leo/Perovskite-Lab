# Perovskite Lab v0.3.1（2026.10.19）

基于 v0.3.0 新增工作表标签重命名和四侧坐标轴设置。

## 启动

双击本目录的 `打开前端-v0.3.1-2026.10.19.command`，使用已构建的网页，无需安装 Node 依赖。默认地址为 http://127.0.0.1:4173/ 。如旧版服务占用 4173，请先在旧服务终端按 Ctrl+C，再启动新版。

自选端口运行：

```sh
python3 启动服务-2026.10.1.py --port 5181
```

## 使用

- 工作表底部标签：双击标签或点击铅笔按钮重命名。Enter 或离开输入框保存，Esc 取消；支持 1–40 个字符，自动去除首尾空格，空名称会提示修正。
- 五张工作表均支持独立改名：原始光谱、样品信息、分析对象、校准数据、梯度配液。新名称同步显示于工作表顶部和底部，保存后切换页面、刷新均保留。
- 各工作表顶部的「名称、单位、备注」三行可直接点击编辑；覆盖五张表的全部列，切换页面和刷新后保留，自定义列信息按列标识保存。列单位作为工作表标注，实际浓度换算仍使用数据区和分析设置中的单位。
- 图表「样式 → 坐标」：选择下轴、上轴、左轴或右轴，分别修改名称、轴显示、刻度标签显示、刻度线方向（向内／向外／内外／隐藏）、长度、粗细和分段数。
- 刻度长度 0–20、粗细 0.5–5、数值轴分段数 1–20。分类轴按对象逐项显示刻度。
- 上／下轴共用 X 数据范围，左／右轴共用 Y 数据范围。默认保留下轴和左轴，上轴和右轴可按需启用。名称留空时隐藏该轴名称。
- 设置会自动保存到当前浏览器；PNG、SVG、PDF 导出沿用当前四轴样式，文件名统一包含 v0.3.1 与 YYYY.M.D 日期。
- 旧工作区存储键保留，缺少新字段时按原有样式显示。自动恢复需要在同一浏览器、同一地址与端口下打开；不同端口的浏览器存储彼此独立。

## 验证

TypeScript 检查与生产构建通过，47 项单元测试和 35 项浏览器测试通过。浏览器测试针对最终 dist 构建执行，覆盖五表全部 31 列的名称／单位／备注编辑与保存、原有数据及撤销不受影响、五表重命名、保存与取消、空名称、刷新恢复、四轴独立设置、刻度方向与长度、三种图表导出、旧数据兼容、手机宽度、大字号长分类标签，以及原有导入、计算、复制粘贴和撤销流程。

已人工检查标签、四轴和长标签图表预览；PDF 可读取上轴、右轴中文名称。构建仍有原有的大分包提示。

## 开发

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm test
pnpm test:browser
```

测试默认连接 http://127.0.0.1:5173/；使用其他端口时设置 LAB_URL。

同目录中带 v0.2.0 或旧日期的文档与组件名称为沿用的历史文件；当前应用版本以 package.json 和 src/version-v0.3.1-2026.10.19.ts 为准。
