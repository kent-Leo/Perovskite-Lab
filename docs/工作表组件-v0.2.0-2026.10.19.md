## 本轮功能

- A(X)、B(Y) 等列标；可编辑的名称、单位、备注行。
- 单元格编辑，拖动或 Shift 扩展选区，整行、整列、全表选择。
- Excel 区域、CSV、TXT 数据粘贴；复制选区为 TSV。
- 缺失的末尾数值会清空旧单元格；粘贴校验失败时整批不写入。
- 撤销/重做、清空选区、添加空行、分页导航。
- 只读计算列保护；选区数值计数、均值、总和。
- 数值、文本、复选框、枚举选项及颜色列接口。
- 方向键/Tab 移动；Enter 换行；F2 在单元格内编辑；⌘/Ctrl+Z 撤销；Shift+⌘/Ctrl+Z 重做。

演示页用 D 列展示 B − C 的自动计算，列名和两组光谱数据可自由修改。上方“值”栏编辑当前单元格，不执行公式表达式。

## 接入方式

```tsx
import { Worksheet } from '../components/Worksheet-v0.2.0-2026.10.19';
import type { WorksheetColumn } from '../domain/worksheet-v0.2.0-2026.10.19';

const columns: WorksheetColumn[] = [
  { key: 'x', title: '波长', designation: 'X', type: 'number', unit: 'nm' },
  { key: 'y', title: '自定义样品', designation: 'Y', type: 'number', unit: 'a.u.' },
];

// rows 是 string[][]，由使用组件的页面持有。
<Worksheet book="光谱工作簿" sheet="Sheet1" columns={columns} rows={rows} onChange={setRows} />;
```

`onChange` 的第二个参数提供操作类型和选区。`onMetadataChange` 更新列信息；`onAddColumn` 由页面决定新增列；`onPaste` 可替换默认粘贴逻辑，供后续光谱列映射使用。`cellLabel`、`invalidCell`、`renderCell` 支持业务页面的可访问标签、错误提示及自定义单元格。

组件不持久化业务数据。页面应维护原始字符串，计算列通过 `readOnly` 声明并由页面重算；撤销历史只比较可编辑值，不因计算结果变化而失效。外部替换数据或改变可编辑列结构会清空旧撤销记录。

粘贴限制：20 MB、100001 行、64 列、500000 个单元格；最多保留 20 次撤销，并根据数据规模限制历史内存。每页显示 20 行。
