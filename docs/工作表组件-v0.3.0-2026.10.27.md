# 工作表框架 · v0.3.0 · 2026.10.27

应用版本为 v0.9.1，工作表框架独立标记为 v0.3.0。版本常量位于 `src/domain/worksheet-v0.3.0-2026.10.27.ts`，组件位于 `src/components/Worksheet-v0.3.0-2026.10.27.tsx`。

独立示例入口为 `/worksheet-v0.3.0-2026.10.27.html`。保留区域复制粘贴、撤销/重做、键盘导航、行列插入、行排序、表头编辑、多 Sheet 和外部历史记录功能。

本版增加两个可选属性：

- `rowClassName(row)`：设置数据行样式。多探针模块用浅色标记空白行。
- `readOnlyCell(row, column)`：设置某个单元格只读，同时应用于单元格编辑、双击编辑及顶部内容栏。多探针空白行的样本信息使用此属性。

区域粘贴的业务约束由模块的 `preparePaste` 与数据转换函数统一校验，整块验证通过后再提交。该扩展为可选配置，其他模块沿用已有交互。

专用单元测试为 `tests/worksheet-v0.3.0-2026.10.27.test.ts`，浏览器测试为 `tests/browser/worksheet-v0.3.0-2026.10.27.spec.ts`。
