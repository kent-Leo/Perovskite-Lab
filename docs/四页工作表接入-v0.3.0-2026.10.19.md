# 四页 Origin 式工作表接入 v0.3.0

日期：2026.10.19。主应用版本由 0.1.0 升至 0.3.0；共用工作表基于 v0.2.0 组件扩展，独立演示入口继续保留。

## 本次修改

| 页面 | 工作表内容 | 保留的业务行为 |
| --- | --- | --- |
| 光谱工作台 | 原始光谱、样品信息两张表 | 起始行、表头、波长/强度列映射；批次更新；原始数据保留；归一化、峰值、数据提取及图表导出 |
| 对象筛选 | 名称、角色、浓度、单位、强度、备注；只读响应列 | 自由名称、明确指定空白、响应转换、拖动行号或按钮排序、删除及 Excel 导出 |
| 校准与检出限 | 浓度、强度、拟合勾选；只读响应列 | 拟合范围、浓度单位转换、含截距普通最小二乘拟合、残差、σ、LOD/LOQ、Excel 导出 |
| 浓度梯度 | 可编辑目标浓度；只读组别、母液/固定添加/溶剂/最终体积 | C₁V₁=C₂V₂、固定体积扣除、母液与溶剂体积约束、批量输入及 Excel 导出 |

全部工作表支持区域选择、复制粘贴、键盘导航、撤销重做和分页。计算结果列禁止粘贴覆盖。光谱样品表只修改已经存在的光谱信息，新增光谱通过原始数据绘图或文件导入。

校准表 A/B 列依次为浓度/强度，可直接粘贴两列数值；新增点默认参与拟合。C 列可粘贴 true/false 或 1/0 控制是否参与拟合。对象表枚举列支持中文标签和内部枚举值；粘贴内容不在选项内时整批拒绝写入。

浓度梯度可直接将一列目标浓度粘贴到 A 列。错误和中间输入保持可编辑；出现错误时不导出配液结果。清空中间目标不会把后续数据移到上一行。
