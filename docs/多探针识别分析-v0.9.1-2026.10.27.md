# 多探针识别分析 · v0.9.1 · 2026.10.27

应用版本统一为 **v0.9.1**；表格框架独立使用 **v0.3.0**。本次将“原始强度”和“空白与批次”合并为“实验数据”，空白与样品共享探针列，并通过稳定的批次 ID 关联。

## 使用方式

双击项目根目录的 `打开前端-v0.9.1-2026.10.27.command`，或运行 `npm run dev`，打开“多探针识别分析”。

1. 在“探针管理”设置探针名称、顺序和参与分析的探针。
2. 在“实验数据”点击“添加空白”，填写批次名称及各探针 F₀。每批保留一组 F₀。
3. 点击“添加样品”，选择批次，填写样本 ID、离子种类、平行编号及各探针 F。仅有一个批次时，新样品沿用该批次；多个批次时明确选择，批次筛选状态下沿用当前批次。
4. 用“批次筛选”查看该批次空白和样品。筛选后编辑或排序只作用于可见记录，其他批次保留。
5. 在结果视图查看猝灭率、PCA、方差解释率和聚类结果；支持图形导出、完整 Excel 和只读结果 Sheet。

表格列顺序如下：

| 类型 | 批次 | 样本 ID | 离子种类 | 平行编号 | 探针 1 | 探针 2 | …… |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 空白 | 批次甲 | | | | 1000 | 800 | |
| 样品 | 批次甲 | S01 | Fe³⁺ | 1 | 600 | 480 | |
| 样品 | 批次甲 | S01 | Fe³⁺ | 2 | 620 | 490 | |

浅色行为空白，其样本 ID、离子和平行编号不需要填写，单元格只读。空白行强度为 F₀，样品行强度为 F。每行的各探针数据应来自对应的同一次实验。

## Excel 粘贴与导出

可从“类型”列粘贴整块数据，也可只粘贴部分区域。类型接受“空白”“样品”，同时兼容 `blank`、`sample`。同一粘贴区域中的空白可以位于样品下方；系统先读取全部批次，再解析样品关联。

带表头的整块粘贴须与当前列名及探针顺序一致。完整导出的“实验数据”Sheet 可以连同表头、末尾的“批次 ID”“记录 ID”列一起粘贴；回贴会重新建立本工作表的 ID，并按批次名称解析关联。

不存在或含糊的批次、无效类型、空白行中多填的样本信息会拒绝本次整块粘贴，保留原数据。空缺、非数值或非正 F₀ 在表中定位，空值不补零。批次名称重复时保留各条原始记录并提示修正。

Excel 包含 8 个 Sheet：实验数据、猝灭率、PCA得分、PCA载荷、方差解释率、聚类结果、Ward合并、分析设置。“实验数据”同时导出空白、样品和对应关系 ID，其余结果仅包含样品。导出文件名包含 `v0.9.1` 与 `YYYY.M.D` 日期。

## 计算及数据兼容

- q = (F₀ − F) / F₀；Q = q × 100%。F₀ 必须为有限正数，F > F₀ 时保留负 q。
- 空白行只提供 F₀，不进入 PCA、聚类和响应热图；每次样品平行实验独立参与分析。
- PCA、Ward、预处理、图形设置及结果快照继续使用既有算法和机制。
- 数据沿用 schema `1` 和 `perovskite-lab-workspace-v1` 本地存储键。原有 `batches`、`rows`、探针 ID 和原始强度保留；新增的可选 `inputOrder` 仅记录统一表中的类型与行 ID。旧数据缺少该字段时先显示空白，再显示样品。
- 拖动行号改变显示顺序，批次改名和行移动均保留 ID 关联。已被样品引用的空白须先重新分配关联，才能删除或转换类型。
- 数值、结构和行顺序使用同一套撤销/重做记录；来源数值改变后，已有只读快照提示重新分析。

目前每批一组 F₀，同批多次空白测量的均值或逐次配对不在本版自动推断。
