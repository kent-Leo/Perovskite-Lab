# CSV 导入说明

更新日期：2026.10.1。以下均为格式示例，不代表实验结果。

## 光谱：波长 + 强度

在光谱工作台选择“光谱宽表”。每条曲线至少两个有效点。同一条曲线的波长不能重复。波长目前按 nm 处理。

```csv
Wavelength,Blank,Sample A
500,100,60
510,200,120
520,100,60
```

波长列选择 Wavelength；勾选 Blank、Sample A 两个强度列，即可叠加两条曲线。单光谱只需两列 `Wavelength,Intensity`。

## 光谱长表：样品 + 波长 + 强度

```csv
Sample,Wavelength,Intensity
Blank,500,100
Blank,510,200
Sample A,500,60
Sample A,510,120
```

选择“光谱长表”，分别映射名称、波长和强度列。样品名称自由填写。

## 对象筛选：名称 + 强度

```csv
Name,Intensity
Blank,12000
Cd2+,2800
Sample A,11350
```

选择“对象筛选”。浓度可省略，浓度列选择“不提供浓度”。也支持三列 `Name,Concentration,Intensity`，单位在界面中设置。导入后如使用 F/F₀ 等响应，需明确选择空白参考；直接绘制原始强度时选择响应方式 F。

## 线性拟合：浓度 + 强度

```csv
Concentration,Intensity
0,12000
1,10920
2,9940
```

选择“校准数据”，并选择正确的浓度单位。仅有名称和强度不能确定浓度拟合关系。

## 文件与映射规则

- 建议 UTF-8 编码、英文逗号分隔。也可手动选择制表符、分号、竖线或空格；中文乱码时改用 GB18030 / GBK。带 BOM 的 UTF-16 文本会自动识别；无 BOM 的 UTF-16 LE 可手动选择。
- 数值单元格只放数字。使用小数点 `1.25` 或科学计数法 `1.2E3`；不要写 `500 nm`、`123 a.u.` 或小数逗号 `1,25`。单位写在列名或界面中。
- 列名可以是中文或英文，顺序可以调整。常见“波长 / Wavelength / nm”“强度 / Intensity / F”“名称 / Sample / Name”“浓度 / Concentration”会自动匹配；其他列名请手动确认映射。
- 没有列名时取消“起始行包含列名”。有仪器说明行时，起始行设为列名所在行；没有列名则设为第一条数据所在行。文本中的空行保留行号。
- 自动建议扫描前 1000 行。说明部分更长、布局特殊或有多段数据时，请手动选择起始行和分隔符。
- CSV 内含逗号的名称需用英文双引号包住，例如 `"Sample A, replicate 1"`；引号必须正确闭合。
- 单文件不超过 20 MB，单曲线不超过 100000 点。

导入窗口可展开“查看 CSV 格式与下载模板”，下载当前布局的模板后替换示例数据。

## “没有有效数据”的排查

1. 预览里所有内容在一列：分隔符不匹配。
2. 名称被当作波长：数据布局或列映射不匹配；名称–强度表应选择对象筛选。
3. 数字显示正常但被跳过：检查是否有单位文字、非数字标记、空值或错误浓度。
4. 仅有一行光谱数值：至少需要两个点；无列名时不要勾选列名选项。
5. 导入成功但筛选/校准图没有响应：检查空白参考 F₀、响应方式、拟合范围与选择的数据点。

## 本次修复

- 修复两列对象文件默认指向不存在的第三列，自动省略浓度。
- 根据常见列名和实际数值建议映射，工作表和数据布局切换时重新建议映射。
- 根据数据行识别分隔符，减少仪器说明行对识别的干扰；支持 Excel `sep=;` 等声明。
- 保留文本空行，使起始行与原文件对应；修复数据在第 30 行之后时列选项不完整的问题。
- 修复无列名光谱长表把第一条样品数据当成列名的情况。
- 对单列、缺失映射列、非数值波长/强度和无效浓度显示具体提示，提供当前布局模板。

未获得报错原始 CSV，本次验证使用上述典型问题的复现文件。如特定仪器文件仍无法导入，需要该文件才能确认其具体布局。
