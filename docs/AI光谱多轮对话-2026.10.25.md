# AI 光谱助手多轮对话升级 · 2026.10.25

## 改造范围

基于远端 main 的 `42d0a8f` 增量修改。原有 TXT/F-7100 解析、Hampel/MAD 检测、局部插值、保护区、结果确认、Excel 导出及 Sheet 同步继续复用。之前用户撤销的更改仍留在独立 Git stash 中，没有重新应用。

聊天输入全部通过 `POST /api/ai/chat` 调用所选 DeepSeek/OpenAI 模型；`interpretAssistantCommand` 仅用于界面上明确标记的本地快捷操作。无文件时可进行普通问答。

## 接口与边界

请求沿用个人 Key 的 Authorization 请求头；JSON 请求体仅包含 provider、model 和 input。input 包括 question、history、context。服务商和模型继续使用现有白名单，不能指定任意 URL。Worker 无状态转发，不保存 Key 或对话，也不记录请求内容。

- 问题最多 2000 字符，模型回复最多 6000 字符。
- 每次提供最近最多 20 条历史，累计最多 24000 字符；只接受 user/assistant 角色。
- 每个文件独立维护对话、草稿、请求和参数建议，页面内最多显示最近 100 条对话。切换模块保留会话；刷新页面沿用原有策略清除上传文件与对话。删除文件会取消请求并清除对应会话，不删除已同步的 Sheet。
- 上下文包含实际文件名、格式、有效点数、激发波长、溶剂、实测扫描范围、原始最大值、算法主峰候选、异常摘要、散射候选、保护区、算法参数、空白设置及预览/确认状态。当前参数和旧预览参数分别提供，避免把旧结果当作新结果。
- 大文件发送全谱计算摘要和最多 384 个原始测量点，优先保留最大值、主峰、前 12 个异常和提问波长附近的数据，其余采用均匀抽样。最多提供 80 条异常摘要及完整异常计数。完整点集与抽样点集有明确标记；局部区间也可能抽样，模型不能声称检查了未提供的点。
- 普通问答返回 `{reply, operation:null}`。数据操作只允许 `{type:'update-parameters', sessionId, revision, parameters}`，类型、枚举、数值、奇数窗口及波长范围均在前后端严格校验。拒绝强度数组、代码、外部 URL、确认、导出或同步等额外执行权限。
- 建议经用户点击“应用建议并生成预览”后，调用现有本地算法生成预览并使旧确认失效。仍须使用原有“确认处理结果”按钮，之后才能导出或同步。数据/参数变化后，旧建议不能应用。
- 当前采用非流式 JSON 响应，完整校验模型输出后展示。55 秒后端超时、60 秒客户端超时；取消和重新生成不会自动重试收费请求。错误单独显示，不伪装成模型回复。
- 已配置的两家服务商 Key、常见 sk- 和 Bearer 密钥形式会在进入对话/历史/审计导出前脱敏；Key 设置仍单独保存在浏览器既有的专用设置中。
