# 宋体来源与授权 · 2026.11.3

图表选项「宋体（Noto Serif SC）」使用本地内置的 `Perovskite Lab Song`，不依赖用户电脑安装字体。预览与 SVG / PNG 使用 WOFF，PDF 使用相同字形的 TTF。

主体来源：[Google Fonts 的 Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc)，原始文件 `NotoSerifSC[wght].ttf`，按 Regular（wght=400）实例化；采用 SIL Open Font License 1.1，授权全文见 `LICENSE-NotoSerifSC-2026.11.3.txt`。这是开源宋体字形，不是 Windows SimSun 字体文件。

为支持 F₀、Fe³⁺、CO₃²⁻ 等科研标记，从已有的 `PerovskiteLabSans-Regular.ttf` 补充 41 个缺失的 U+2070–U+209F 科学上下标字形，按字体 unitsPerEm 缩放，并将衍生字体更名为 Perovskite Lab Song。这部分字形原始来源为 DejaVu Sans，授权见 `LICENSE-DejaVu.txt` 和 [既有字体说明](字体来源与授权-2026.10.1.md)。

输出文件均含 31099 个字形。下载的可变字体与中间文件不随项目保留。
