# 多探针猝灭率直接录入 · 2026.10.28

「多探针识别分析」现直接使用用户录入的猝灭率，取消测定强度 F、空白 F₀ 和批次的录入入口。PCA 得分图、载荷图、Ward 聚类树和响应热图均保留。

打开 `#recognition`，在「猝灭率」表按以下顺序填写或从 Excel 粘贴：

```text
样本 ID    离子种类    平行编号    探针 1    探针 2    探针 3
A          Fe³⁺       1           0.74      19%       0.35
A          Fe³⁺       2           0.71      21%       0.38
B          Cu²⁺       1           -21%     0.10      0.78
```

- 不带百分号的数值按 q 处理；`0.74` 与 `74%` 相同。负值表示荧光增强，`0` 表示无变化。
- 每行仍为独立的平行实验，保留样本 ID、离子标签和编号，不自动求平均。
- 中心化 / Z-score、热图数值选项、多 Sheet、撤销 / 重做、结果快照、图形样式和导出功能保留。
- 缺失值或无效值定位到猝灭率单元格并阻止分析。常量小数列与百分数列均能正确识别为零方差。

旧版工作区中的 F / F₀ 按原有批次关联换算为 q，仅转换一次。原始探针、强度、批次及实验行独立保留；导出 Excel 时附带「历史原始强度」和「历史空白与批次」。旧结果快照保持只读，源数据变化提示继续生效。

新数据导出的 Excel 包含「猝灭率」（q 与 Q (%)）、「PCA得分」、「PCA载荷」、「方差解释率」、「聚类结果」、「Ward合并」和「分析设置」。内部计算与 Excel 保留完整数值精度。
