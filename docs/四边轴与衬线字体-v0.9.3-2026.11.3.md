# 四边轴与衬线字体 · v0.9.3 · 2026.11.3

修改保存在 `feature/v0.9.3` 分支工作区。

## 默认坐标轴

光谱、对象筛选、校准和 PCA 图使用四边轴框：左轴与下轴显示标签、刻度向内；上轴与右轴只显示轴线，默认不显示轴标题、刻度标签或刻度线。新工作区及没有设置相应轴选项的旧工作区均采用此默认值。

已明确保存的各轴设置优先，继续保留自定义标题、方向及显隐。PCA 得分图开放四侧轴设置。Ward 树的数值底轴同样采用向内刻度，树状图与热图保留各自的分类布局。

## Claude 风格衬线

在「图表设置 → 字体」中选择「Claude 风格衬线」。西文采用源自 Lora Regular 的内置字体，中文及缺失的科学符号使用现有宋体回退，支持刷新保存和 SVG / PNG / PDF 导出。PDF 对混排文本逐段计算宽度，兼容居中、右对齐与旋转轴标题。

来源、授权与字体校验值见 [衬线字体说明](../public/fonts/衬线字体来源与授权-2026.11.3.md)。
