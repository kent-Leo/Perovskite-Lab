# Perovskite Lab 技术方案与页面信息架构

日期：2026.9.30；更新：2026.10.1

## 本期边界

构建本地可运行、可静态部署的前端科研工作台。浏览器内处理用户文件，无服务器上传。支持 XLS/XLSX/CSV/TXT、映射与预览、单/多光谱、归一化、峰值摘要、自定义对象与筛选、浓度校准、普通最小二乘拟合、R²、LOD/LOQ、梯度配液、图表编辑与 PNG/SVG/PDF 导出。示例数据为人工生成，明确标记。卤素交换计算不实现。实验记录、项目、文献仅预留类型及服务接口。

## 信息架构

| 页面 | 核心区域 | 输入 → 输出 |
|---|---|---|
| 光谱工作台 | 数据导入、样品列表、光谱画布、样品元数据、样式面板 | 单/多文件 → 光谱与峰值摘要 |
| 对象筛选 | 自定义对象表、空白指定、响应转换、柱状图 | 名称/角色/浓度/单位/F/备注 → 选择性图 |
| 校准与检出限 | 浓度-F表、目标浓度单位、响应转换、拟合范围、空白重复测量、拟合图 | 指定波长提取或表格导入 → 方程/R²/LOD/LOQ |
| 浓度梯度 | 母液、单位、目标梯度、最终体积、固定添加体积 | C₁V₁=C₂V₂ → 配液表及 Excel |
| 后续扩展 | 接口规划 | 实验记录、项目管理、文献数据库 |

图表样式和导出共用一个组件，紧邻图表；无需跳转独立编辑页。导航采用 URL hash，刷新和浏览器返回保留当前页面。

## 前端技术与目录

React + TypeScript + Vite；Lucide 图标；SheetJS 0.20.3 读取 Excel；Papa Parse 读取分隔文本；原生 SVG 绘制科学图表；pdf-lib + fontkit 导出完整嵌入中文和科学字符字体的矢量 PDF。仅请求本机静态资源，运行时不依赖在线 CDN。

`domain/`：数据类型、纯函数数值计算与 SVG 图形生成。

`services/`：导入、下载、图表导出和未来仓储协议。

`state/`：版本化浏览器工作区状态与示例数据。

`components/`：共用画布、图表编辑、导入弹窗和表单。

`features/`：四个业务页面及扩展说明。

`tests/`：数值边界与浏览器功能验证。

## 数据与计算约定

1. 原始光谱保留；按波长排序。无效行统计并提示；重复波长拒绝导入该曲线，以免隐式平均。
2. 单/多光谱只由可见样品决定；归一化使用各曲线自身 Imax。非正最大值不能归一化。峰面积为测量范围内原始光谱的梯形积分；FWHM 按零基线主峰两侧半高交点线性插值，未覆盖交点返回不可计算。
3. 筛选支持 F、F/F₀、F₀/F、(F₀−F)/F₀ 和猝灭率%。空白由用户指定；除零时拒绝计算，不伪造零值。
4. 校准为含截距的非加权普通最小二乘拟合。至少两个不同浓度；两点可以拟合但提示不能估计残差。常量响应 R² 未定义；重复浓度保留为重复观测。浓度统一到用户指定的同一单位。范围由用户明确选择，不自动寻找“最好看的”R²。
5. 光谱指定波长强度用相邻测量点线性插值，不越界外推。
6. LOD=aσ/|k|（a=3 或 3.3），LOQ=10σ/|k|。σ 使用空白重复响应的样本标准差（n−1），或用户手动输入拟合纵轴尺度下的 σ；F₀/F 使用原始空白重复值逐一变换再求标准差。归一化的 F₀ 使用固定参考值，不将每个重复值分别归一化为 1。至少三次空白重复测量，σ=0 或斜率=0 不报告有效检出限。结果是公式估计，需实验验证。
7. 梯度的母液与目标浓度使用同一单位，输出 μL 母液和最终 mL 体积；若存在固定添加的量子点/缓冲液体积，从补加溶剂中扣除。提示加溶剂定容，简单体积差仅作为计划值。
8. PNG 通过指定物理宽度与 300/600 dpi 计算像素，并写入 PNG pHYs 元数据；SVG/PDF 保留矢量。SVG/PNG 使用用户选择的字体；PDF 使用随项目分发的 Perovskite Lab Sans（由 Noto Sans SC 与 DejaVu 科学字符组成），完整嵌入字体以保证兼容；SVG 在需要中文/科学字符时嵌入字体，支持离线打开。

## 后续接口

`Repository<T>` 预留 list/get/create/update/remove；`Experiment` 关联原始谱、对象、校准和图表；`Project` 关联实验与文献；`Literature` 保存 DOI 和基本元数据。当前无远程请求、认证或虚假保存按钮。未来由实现这些协议的 HTTP 或 IndexedDB 适配器接入。
